# Assignment 3 - Dynamic Dropdowns & Checkboxes

## Objective
Demonstrate Selenium automation of:
1. An autocomplete/dynamic suggestion field.
2. Multiple checkboxes.

## Requirements Demonstrated
- WebDriverWait
- Dynamic autocomplete suggestions
- Selecting a matching suggestion
- Checkbox interaction using click()
- Verification using is_selected()

## Run

```bash
pip install -r requirements.txt
python assignment3_dropdowns_checkboxes.py
```

Expected output:

```text
Autocomplete selection PASSED
Checkbox selection PASSED
Assignment 3 PASSED
```
